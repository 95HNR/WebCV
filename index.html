Projects

DriveCheck

Client-Server Fleet Management

The DriveCheck system is a software-based fleet and trip management solution for small and medium-sized enterprises. It consists of two independent Android apps: a Client (driver) and a Server (administrator).

Key Concept: It replaces paper-based administration with a digital, cost-effective "Bring Your Own Device" approach, avoiding the need for expensive GPS hardware.

Security: By communicating via a local network (HTTP), sensitive data remains within the company's internal environment.

Client App: It focuses on quick data entry and uses the OpenStreetMap API for accurate, predictive address input to minimize errors.

Server App: It acts as a central hub for managing the vehicle fleet and approving or rejecting trip requests through an automated workflow.

Technology: Both apps are native Java-based Android applications using Room Database for reliable local storage and RecyclerView for efficient data display.
