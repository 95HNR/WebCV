Projektek

DriveCheck Kliens-Szerver Flottamenedzsment

Szoftveralapú fuvar- és járműpark-kezelő rendszer kkv-k számára. Két önálló natív Android alkalmazásból áll: Kliens (sofőr) és Szerver (adminisztrátor).

  • Koncepció: Kiváltja a papíralapú adminisztrációt BYOD modellben, elkerülve a drága GPS hardvereket.
  • Biztonság: A lokális hálózati kommunikációnak (HTTP) köszönhetően az érzékeny adatok a cég belső környezetében maradnak.
  • Technológia: Natív Java Android alkalmazások, Room Database (helyi tároló), RecyclerView és OpenStreetMap API integráció.
